# 健康与财务能力的实际依据

检查日期：2026-11-06。以下说明基于本发布树中的代码和技能，不把对话里讨论过的规划当成已部署能力。

## 共同工作流

用户请求 → 按需加载领域技能 → 读取用户明确确认的相关档案 → 用宿主可用工具读取文件或联网核验 → 分开说明事实、估算、假设与建议 → 用户明确交办时记录任务或提醒。

档案带用户隔离、source、confirmed、updated字段；没有专门的医学知识图谱或财务资产数据库。source是文本，不是自动校验过的引用。技能约束主要通过模型指令实现，不等同于每个建议都已经通过程序化专业审核。

## 健康

实现依据：skills/assistant-health/SKILL.md、src/assistant/health.mjs、现有memories存储。

- 用户资料：本人提供并要求保存的目标、疾病、过敏、用药、运动限制；不会从收藏或照片推断疾病。
- 数据处理：健康主档为文本；餐食有时间、食物、份量和备注。七天回顾依据实际记录天数，不补造缺失数据。
- 生活推荐：小红书用于菜式、健身视频和就诊经历线索；疾病、药物、禁忌必须转卫生机构、临床指南或原始研究核验，并提供日期与链接。
- 照片：只解释实际可见内容；份量和热量为带假设的估算，不能根据照片确诊。
- 尚缺：经过审查的医学论文/指南知识库、系统化证据分级与更新机制、药物相互作用数据库、临床准确性验收。没有自动挂号和处方能力。

因此当前适合健康资料和日常生活辅助，不应宣传为专属医生或诊断系统。

## 财务

实现依据：skills/assistant-finance/SKILL.md、src/assistant/stock-report.mjs、finance档案分区、办公工具和原生任务。

- 用户资料：明确要求保存的财务背景；报告优先使用用户提供的原文件。
- 外部来源：规则要求优先发行人、交易所和监管公告；财经媒体用于补充。报告期、获取时间、币种、单位、年化和复权口径要区分。
- 计算：使用宿主脚本或表格工具，不存在本项目独立、经过审计的财务计算引擎。
- 股票播报：按用户指定标的检索；公司消息不足才补相关行业热点，标明日期。仅根据当前任务确定关注范围，不随包携带作者名单。
- 当前校验：validateStockReport仅检查基本篇幅、标题和来源链接存在，不能证明行情数字或新闻结论正确。
- 尚缺：银行/券商接入、自动记账与对账、资产负债账本、经过验证的实时行情源、组合风险/税务引擎、专业投研准确性验收。不会交易、转账或保证收益。

因此当前更准确的定位是财经资料整理与定时研究助手，尚不是完整个人财务管理系统。

## 测试含义

代码回归验证工具接口、隔离、记录、时间逻辑和失败处理，不验证临床结论或投资判断的专业正确性。源码上传可以说明这些基础能力，但不能据此宣称专业领域已达到医生、投顾或家族办公室服务水平。
