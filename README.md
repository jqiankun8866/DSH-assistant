DSH-assistant 基于 **DeepSeek Harness（DSH）**，将模型与工具能力接入微信。发一句话、一张照片，或一份文件，让大肥鱼帮你找穿搭、整理资料、处理文档和安排提醒。

你可以设定它的称呼与说话方式，把明确的偏好保存下来；也可以在本机控制台查看和修改个人档案、任务与表情包设置。

## 你可以让它做什么

### 👗 从小红书收藏，找到你喜欢的穿搭

收藏了很多穿搭，却不知道怎么用到自己身上？授权读取收藏后，大肥鱼可以从实际读到的内容中归纳风格线索，与你确认后记入个人档案，用于后续推荐。

- **发单品，找搭配**：识别衣服的颜色、深浅、版型和风格，再搜索合适的搭配。
- **按场景推荐**：结合你提供的身材信息、风格偏好和出行场景，推荐整套穿搭。
- **配饰一起考虑**：除了上衣、裤子和鞋子，也关注包、首饰等配饰。
- **给你看真实参考**：能获取到配图时发送图片，并附原帖链接；无法获取时提供链接。
- **根据反馈调整**：告诉它“太正式了”“喜欢这套配色”，逐步明确你的偏好。

> “看看我最近收藏的穿搭，总结我喜欢的风格。”<br>
> “这条棕色阔腿裤，帮我找三套夏天出去玩的搭配，鞋和包也配上。”

小红书需本人登录。收藏分析基于当次实际读取到的内容，不代表已遍历整个收藏夹；视频分析取决于内容是否可获取，以及模型的视觉能力。

### 🐟 会用表情，也能更新自己的表情库

内置 **26 张戴眼镜秘书大肥鱼表情**，另有一张模型额度不足时使用的提示图。聊天时结合语境选择表情，让回应更有生活气息。

- **定期收集**：启用后，按设定频率从小红书搜索并收集表情包，优先选择带文字的图片。
- **保存你分享的表情**：把微信里收到的表情存进图库，供以后聊天使用。
- **理解含义再选图**：通过视觉标注记录情绪、文字与使用场景，辅助匹配对话。
- **控制台管理**：设置采集开关、频率，打开本地图库管理图片。

> “把这个表情包存起来，以后聊天可以用。”<br>
> “启用表情包自动收集，每 84 小时更新一次。”

自动采集默认关闭，启用后需要小红书登录状态和相关识图、OCR 能力可用。

### 🧠 记住你的偏好，整理你的个人资料

设定喜欢的称呼、语气和回复长度，把需要长期保留的信息告诉它。资料可以通过对话或图片整理，在控制台中查看、修改。

| 分类 | 可以整理的内容 |
| --- | --- |
| 基础与偏好 | 称呼、日常偏好、沟通习惯 |
| 健康与饮食 | 身体情况、血型、既往体检资料、近期饮食记录 |
| 穿搭 | 风格偏好、单品信息、对推荐结果的反馈 |
| 财务、法务与生活 | 相关资料、个人背景和需要后续处理的事项 |

> “以后叫我老大，平时回复短一点。”<br>
> “这是我的体检报告，帮我整理进健康档案，标出需要关注的项目。”

### 📋 把工作和生活里的琐事交给它

| 能力 | 你可以这样说 |
| --- | --- |
| 办公文档 | “把这些资料整理成一份汇报 PPT。” |
| 图片、语音与视频 | “总结这段视频，提取关键内容。” |
| 任务与提醒 | “每个工作日早上九点，发我关注股票和相关行业的新闻。” |
| 邮件阅读 | “看看有没有需要我处理的重要邮件。” |
| 健康资料分析 | “结合我的档案，分析这份报告，列出就医时要问的问题。” |
| 财经信息整理 | “整理这家公司的近期消息，没有新消息就看看行业热点。” |
| 合同阅读 | “检查这份合同的付款、违约和解除条款，列出需要确认的地方。” |

办公处理复用 DSH 的 Word、PPT、Excel、PDF 环境；语音和视频处理需要相应模型及媒体依赖。邮件支持 TLS IMAP 读取与疑似重要邮件提醒，当前每位用户配置一个邮箱，不自动发送回复。

## 本机控制台

安装后运行项目中的 **“打开大肥鱼面板.cmd”**，即可集中管理：

- **人设**：称呼、表达风格和相处方式。
- **个人档案**：按分类查看、修改已整理的资料与偏好。
- **任务**：查看和管理在微信中安排的任务与提醒。
- **表情包**：控制自动采集开关、更新频率，并打开图库。

微信与控制台共用任务状态，提醒使用 DSH 原生任务能力。

## 快速开始

### 1. 准备环境

当前支持 **Windows**，本版适配 **DeepSeek Harness 0.2.1-rc.5**。先安装并打开 DSH，配置可用模型；图片理解等能力还需要模型支持相应输入。

安装流程会检查 Node.js 24+、Python、DSH Office 等环境，并补齐支持的依赖。部分资源需要联网下载，账号登录和授权需要本人完成。

### 2. 下载项目，交给 DSH 安装

从本仓库页面选择 **Code → Download ZIP**，解压到固定的个人目录；也可以克隆仓库：

```bash
git clone https://github.com/jqiankun8866/DSH-assistant.git
```

将项目文件夹路径发给 DSH，并附上：

> 请阅读这个项目的 INSTALL-IN-DSH.md，按指南校验文件、检查环境并执行安装。复用我现有的模型配置，不打印密钥。完成后告诉我哪些功能已验证、哪些需要我登录或授权。

详细流程见 [DSH 安装指南](INSTALL-IN-DSH.md)。请将项目保存在固定目录，不要放在微信临时缓存或 DSH 程序安装目录中。

### 3. 连接微信，开始使用

按 DSH 的引导完成微信扫码，安装结束后按提示重启 DSH。在微信中发送“你好”，再试试“发一个比心表情包”，确认收发正常。

使用小红书时，在专用 Chrome 中完成本人登录；使用邮箱时，在本机配置窗口填写账号和授权信息。邮箱配置见 [接入说明](docs/EMAIL.md)。

## 常见问题

**提醒和自动采集需要电脑开着吗？**<br>
需要电脑与 DSH 保持运行。提醒时间、采集频率由你设定；新安装不会自动订阅股票晨报或其他提醒。

**小红书需要每次手动打开吗？**<br>
请求时会检查并启动专用 Chrome，正常读取在后台进行。首次登录、登录失效或平台验证时，需要本人操作。

**记忆和档案存在哪里？**<br>
账号配置、记忆和档案保存在本机。使用模型、微信、邮箱或小红书时，相关输入和请求会发送到对应服务，并非完全离线运行。

**健康、财务和合同分析可以直接替代专业意见吗？**<br>
这些能力用于整理资料、检索依据、解释信息和提示待确认事项。涉及诊断、用药、投资决策或法律处理时，需要专业人士结合具体情况判断。参见 [健康与财务能力依据](docs/HEALTH-FINANCE-BASIS.md)。
