# 大肥鱼 · DSH 微信私人助理

Windows 开发候选版 **0.1.0**，适配 DeepSeek Harness **0.2.1-rc.5**。保留8个助理技能，移除安卓执行器、梗词库及日记功能。已通过本机自动回归及隔离配置的首次安装/升级测试，尚未完成新Windows机器及本版本真实微信对话验收；见[上传前验收](docs/PREUPLOAD-ACCEPTANCE.md)和[小红书启动验收](docs/XHS-BROWSER-STARTUP.md)。

通过微信处理日常事务、文件与用户分享的内容，保留称呼和明确偏好。提醒使用 DSH 原生任务，微信和本机控制台共用任务状态。

## 能力

- 微信文字、图片、语音、视频音轨/抽帧和文档处理。
- Word、PPT、Excel、PDF：复用 DSH 的办公运行环境。
- 本地长期记忆、人设；健康档案、七天饮食记录需本人授权。
- 穿搭推荐：按需加载独立技能，识别单品与配饰、宽检索后看图核对、同色系比较及收藏偏好确认；不是自动分割或专用训练模型。
- 个人档案增加穿搭、法务、生活分区和分页检索，复用原记忆库。
- 统一任务增加步骤、材料、下一步、等待原因、截止信息及完成结果；截止日不自动建立提醒。
- 统一公开内容读取入口、24小时缓存、定向查询与后台浏览器/截图回退指引。Envoy未随包安装；动态页面、视觉读取仍依赖宿主实际能力。
- TLS IMAP 邮箱只读查询和重要邮件初筛提醒；支持QQ兼容配置、Gmail/iCloud预设及自定义服务器，当前每用户一个邮箱。详见 [邮箱接入](docs/EMAIL.md)。
- 小红书后台浏览、搜索、笔记图片、收藏/点赞读取；需本人登录专用 Chrome。
- 表情收集、一次性视觉标注、语义选图、每轮配图及辅助模型用量记录。

基础素材使用随包署名的 Twemoji。**不包含作者的个人图库、小红书采集图片、聊天记录、邮箱凭据和账号登录状态。** 医疗能力不代替医生诊断；投资资料不执行交易。

## 安装：交给 DSH 操作

1. 安装并打开 DSH，配置可用模型。
2. 下载本仓库 ZIP，或克隆到固定的用户目录。
3. 将项目文件夹路径和下面这句话发给 DSH：

> 请阅读此项目的 INSTALL-IN-DSH.md，按其中流程校验文件、检查环境并安装。复用我的模型配置，不打印密钥。完成后列出已验证功能和待授权事项。

具体入口见 [DSH 安装指南](INSTALL-IN-DSH.md)。需要 Node 24+、Python 以及 DSH Office 环境；安装流程检查和补齐支持的依赖，部分资源需要联网下载。微信扫码、XHS 登录、邮箱授权由使用者完成。不要把仓库解压到 DSH 程序安装目录。

安装后运行“打开大肥鱼面板.cmd”。控制台仅监听本机，使用本机生成的访问令牌。提醒依赖电脑和 DSH 保持运行；XHS 请求会检查并自动启动专用 Chrome；首次登录或验证仍由用户完成。新用户没有预设的股票提醒、个人健康记录或邮箱订阅。

## 源码与检查

本仓库同时保留 `src` 和与之配套的 `lib`，便于 DSH 直接执行安装；不是宿主原生一键导入插件格式。

```powershell
python scripts/verify-distribution.py
node scripts/build-channel.mjs
npm test
python -m unittest discover -s scripts -p "test_*.py"
```

完整回归需本机 DSH、Office、FFmpeg 等依赖；安装器正式部署前会运行全部随包测试。纯本地测试不代表真实微信已经送达。Mac、模拟器打车和票务不在本版支持范围；安卓执行器及梗词库的技能、工具、安装步骤与构建产物已从本版删除；表情图片库保留。

小红书首次启动的真实检查：`node scripts/test-xhs-cold-start.mjs`。此可选检查需要 Windows Chrome 和网络，使用全新临时目录及随机端口，测试后关闭该实例；不使用已有登录状态，也不向微信发送消息。

开发者修改源码后，应审查变更、重新构建和测试，再用 `python scripts/verify-distribution.py --write` 更新发布清单。使用者遇到校验失败不要直接重建清单绕过检查。
