# 健康证据库

40 条资料卡：既有皮肤/脱发初筛资料 26 条，本次增加 14 条指南、培训资料、原始研究或官方解读。不是40篇已全文审读论文。

本库保存题录、链接、中文概括、适用局限、核验日期和已读范围，不复制付费论文或教材全文。引用原文仍须遵守各来源许可；代码许可证不覆盖来源材料。

检索：使用宿主的 Python 执行同目录 `search.py "体检"` 或 `search.py "饮食 减脂" --limit 5`。无模型调用、无需新服务，不把整个库放入每轮上下文。

应用流程：查用户相关档案 → 检索最多5张资料卡 → 按适用人群、研究类型、局限筛选 → 核对原文、更新与更正 → 解释与用户决策相关的部分。来源重复不能叠加为独立证据。

这是可选检索路径，不是封闭问答库。最新研究、产品和服务问题可以直接联网，小红书补充真实生活经验；库内无资料不应终止检索。医学结论仍以核验的权威原文为依据，经验贴不替代临床证据。查询对外只发一般问题，不附用户隐私。

资料质量不按期刊名气自动评分。训练课程用于组织咨询与行动支持，不代表临床资格。meta/abstract/overview状态不冒充全文；对照不足、短随访、特殊样本不能泛化。

首批包含WHO生活方式咨询与运动指南、CDC PreventT2教练课程、国家卫健委肥胖相关资料、DIETFITS、DPP、超加工饮食试验、AASM失眠指南、AAD痤疮指南及MedlinePlus检验解释。

资料维护：涉及药物、阈值、禁忌与重要健康建议时重新联网核验；有更正、撤稿或新版时更新卡片并保留说明。当前没有开启自动联网采集或定期任务。
