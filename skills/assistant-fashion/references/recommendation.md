# 穿搭审查与配色

## 锚点、风格与配饰

先固定用户指定单品，再考虑整体风格。灰棕长裤可配出通勤或松弛休闲；不能把原图的条纹开衫、项链和编织包全当成裤子自带的风格属性。

候选逐项核对：品类、色系、轮廓与体量、长度、可见垂感。明确硬要求不符就排除；关键处遮挡或未看图则保留为待核，不用热度补分。深浅、腰线和表面差异单独说明。同色系深浅可以放宽，灰棕不能仅凭标题被暖黄卡其取代。只需要搭配灵感时可以借鉴不同裤子的上装，但必须标明不是相似裤型。

配饰根据作用判断：焦点、颜色呼应、腰线/轮廓、层次、质感对比或功能。面积小不等于不重要；腰间领带与颈部领带、包挂件与项链不可混淆。先看全图，再对影响判断的小细节补看局部，避免重复读取整套素材。

## 配色关系

先按单品区域观察，不拿背景、肤色或阴影作服装色。描述图中呈现的颜色族、深浅、饱和度、冷暖与反光；没有校准不报精确RGB/Lab、色号或面积比例。

分别检查上下装对比、鞋与裤脚衔接、包和首饰的呼应、焦点数量。同色系看深浅、纹理与体量是否形成层次；撞色看是否符合用户偏好和场合。不强制60/30/10，也不把黑白灰当作唯一稳妥选择。

可提出三个方向：保持统一、局部呼应、小面积点缀，按用户偏好选用。相似度和美观度分开：颜色距离小不证明好看，距离大也不必然不协调。即使未来实际取色，ΔE也只能描述照片色差，不能直接当搭配评分。

## 来源与适用边界

本规则整理自本项目2026-11-05的穿搭研究记录，未分发第三方截图、用户收藏或个人画像。以下为此前读取的研究资料索引，不声称复现论文模型；如要回答具体论文结论，重新核对原文。

- [Ou & Luo 2006](https://onlinelibrary.wiley.com/doi/10.1002/col.20208)：双色关系的研究参考，不等于复杂穿搭的通用评分。
- [Gray等2014](https://journals.plos.org/plosone/article?id=10.1371/journal.pone.0102772)：特定实验中的配色偏好，不能据此惩罚所有同色或撞色搭配。
- [Learning Color Compatibility 2020](https://arxiv.org/abs/2007.02388)：可借鉴单品色组与关系表示；本项目没有移植训练权重。
- [Li等2025](https://link.springer.com/article/10.1186/s40691-025-00433-y)：配色评价研究参考，不将研究内部成绩当成本系统准确率。

## 人工验收例

1. 用户要求灰棕长裤夏装：宽搜；冷灰棕深浅不同可保留；冬装或明显不同裤型不能凑作匹配。
2. 用户指定五篇：核对五个独立笔记；同笔记五张图不满足。
3. 用户发了不喜欢的造型：不保存为喜欢；仅用其明确反馈。
4. 用户要学视频搭配：没有帧则不描述鞋包细节；可换图文，不用标题假装看完。
5. 用户已有鞋包：优先复用，新的配饰建议须解释作用而非堆数量。

这些是审查场景，不是已经执行的模型效果测试。
